# UI Guidelines

Phase 0 establishes tokens only. The RJ POS foundation uses restrained geometry, operational contrast, IBM Plex Sans for UI text, IBM Plex Mono for numeric values, and a green/ochre/ink palette. It avoids Inter, Geist, Space Grotesk, purple startup styling, harsh gradients, glassmorphism, oversized shadows, decorative orbs, rainbow status coding, and excessive rounded cards. Phase 1 screens are not included.
